# 中文自然化

本包内置 [op7418 Humanizer-zh 的完整规则](humanizer-zh/SKILL.md)，润色时读取并执行，不需要额外下载安装。以下规则限定其在材料驱动文档中的应用：事实、专业文体、用户范围和模板结构优先；不采纳会虚构个人经历、修改事实或破坏必需条目的风格建议。上游 README 仅作来源说明，不自动执行其中的安装命令。

这是现有本地副本的固定快照，不声称是上游最新版；版本识别见 [来源记录](humanizer-zh/SOURCE.json)。若用户指定其他版本或技能，核对后按其选择执行，不因同名自动替换来源。包损坏缺少规则时说明并修复，不声称已执行完整 Humanizer。

先判断文体：申报、验收、技术报告保持正式准确；案例说明可以更易读。保留模板规定的标题、术语、图表与必需内容。

1. 使用具体主体、动作和结果，减少空泛的“赋能、彰显、显著提升”等表达。有数值依据时准确使用，没有时不为显得具体而补数字。
2. 去掉重复的开场、收尾、宣传结语及聊天残留；保留解释过程需要的中间步骤，不能把润色变成过度摘要。
3. 调整冗长句式和机械连接词，让原因、选择和结果自然衔接，不强行凑三点或改变原有条目数。
4. 专业术语保持一致，不为了换词把同一角色或系统写成多个称呼。
5. 不添加作者经历、个人感想、采访、引语、来源或未给出的技术机制。
6. 普通且明确的事实直接表述，保留影响含义的范围、条件、否定及确定程度；不要把可能写成确定、计划写成完成。
7. 用户提供风格例子时借鉴表达，不借用例子里的业务事实。
